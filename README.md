# TIPPS Dashboard

Live Site: https://tippsdashboard.app

## Overview
TIPPS Dashboard is an AI-powered application designed to help schools analyze survey data, track progress across key pillars, and generate actionable insights.

## Features
- Process Qualtrics CSV survey data
- Track pre/post assessment progress
- Generate dashboards and executive summaries
- Support data-driven decision making

## Privacy
This application only accesses user data within Google Sheets and Google Drive.
No data is shared with third parties.
