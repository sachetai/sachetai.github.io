TIPPS Dashboard Privacy Policy

This Privacy Policy describes how TIPPS Dashboard accesses, uses, and protects Google user data.

Data Access

TIPPS Dashboard accesses Google user data only after explicit user authorization via Google OAuth. The application may access:

  • Google Sheets data selected by the user
  • Google Drive files and metadata selected or created by the user

How Data is Used

The accessed data is used solely for:

  • Importing and processing survey data
  • Updating dashboard spreadsheets
  • Generating analytics and summaries

Data Sharing

TIPPS Dashboard does not sell, share, or transfer Google user data to third parties. Data is only used within the application to provide its core functionality.

Data Storage and Retention

Data is accessed in real-time and only stored as necessary to provide functionality. No unnecessary or unrelated data is retained.

Security

Reasonable administrative and technical safeguards are implemented to protect user data from unauthorized access, use, or disclosure.

User Control

Users can revoke access to their data at any time via their Google account permissions.

AI Integration (Cohere)

This application uses a third-party AI service (Cohere) to generate optional executive summaries based on processed survey data.

  • No personal Google user data is sent to Cohere.
  • Only processed, non-sensitive survey insights may be used.
  • The AI feature is optional and user-triggered.
  • Cohere does not store or reuse submitted data for model training.

This integration is strictly limited to enhancing dashboard insights and does not affect the core functionality of the application.
