TIPPS Dashboard

TIPPS Dashboard is an AI-powered application designed to help schools analyze survey data, monitor progress across key pillars, and generate actionable insights for continuous improvement.

Features

  • Process Qualtrics CSV survey data
  • Track pre- and post-assessment progress
  • Generate dashboards and executive summaries
  • Support data-driven decision making

Google User Data Access

This application integrates with Google APIs and accesses user data only with explicit user consent.

  • Google Sheets – to read and update dashboard data
  • Google Drive – to access files selected by the user
Data is used only to provide dashboard functionality. No data is shared, sold, or used for advertising.
